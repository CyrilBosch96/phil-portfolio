# **App Name**: Visionary Portfolio

## Core Features:

- About Section: Showcase Philip's professional background, vision, and accomplishments with an engaging 'About' section.
- Techjays Overview: Highlight Techjays' projects, metrics, and industry impact through a visually appealing 'Techjays Overview' section.
- Investment Portfolio: Visually represent Philip's investment portfolio, showcasing investment sectors and philosophy.
- Media Mentions: Media Mentions (Interviews, Features, etc.)
- Hobbies: Hobbies (Travel, etc.)

## Style Guidelines:

- Primary color: Deep navy blue (#1a2a3a) for a professional and sophisticated feel.
- Secondary color: Soft gold accent (#d9b777) for highlights and calls to action.
- Background: Clean white (#ffffff) with light gray sections (#f8f8f8) to provide ample whitespace and visual separation.
- Text: Dark charcoal (#333333) for body text and black (#000000) for headlines to ensure readability.
- Accent: Teal (#008080) for interactive elements and subtle highlights.
- Headlines: Elegant serif font (like Playfair Display) to convey sophistication.
- Body text: Clean sans-serif font (like Poppins or Inter) for readability and modern appeal.
- Minimalist layout with ample whitespace for a clean and uncluttered presentation.
- Subtle scroll animations to reveal content and add visual interest.
